# 你的背景与定位：怎么讲，怎么补短

实习面试第一关是让面试官相信你适合这个项目。项目要把网络安全推理和高阶代码能力内化进 GLM，优先要有模型训练、RLHF、CTF 经验的人。你的真实情况是 agent/harness 很强、有安全实操、有不错的研究背景，但没独立训过模型、安全基础也不深。这一篇教你怎么把强项讲够、把短板讲得对你有利。

## 一、你手里真正的牌

别小看自己，你有三张实的牌：

第一张，agent 和 harness 的硬实操。你把大模型接进两套架构迥异的 harness（薄的 pi、重的 ale_claw）在 ALE 这个可验证 agentic 评测集上跑过，还 root cause 了一个模型和 harness 的深层不匹配（模型路由把 gpt-5.6 错配进 Qwen 风格的工具协议循环导致它完全不发工具调用），一行改动修好。这说明你懂 agent 系统的内部，不是只会调 API。

第二张，亲手做过安全题。你在 Linux 上手工解了 4 道安全题：UPX 脱壳后用已知明文攻击还原 XOR 密钥（15 个配置字段全对）、逆出 crackme 的 TEA 变体加自定义 MD5 注册码算法、用 tshark 做企业流量取证认出 NetSupport RAT。你对安全任务有第一手的体感，知道它们长什么样、哪些能自动打分。

第三张，研究背景里就有"内化进权重"这个思想。你硕士做复杂时间序列建模，博士方向是自进化 agent 和 harness–model 协同进化，简历里那句"harness 引导模型 on-policy 产生可学习轨迹，再训练内化进权重，去掉 harness 后模型仍能自我增强"，和这个项目要做的"把安全推理内化进模型底层"是同一个思路。你已经在想这件事了。

## 二、核心定位：你是训练最缺的上游

把三张牌拧成一句定位（`00` 里的长版，这里是逻辑）：这个项目要把安全推理内化进模型，用的手段大概率是在可验证的安全任务上做 RL，让模型自己解题、用成败当奖励，把解题决策写进权重。这条链的上游是环境、轨迹、奖励，下游是训练循环和调参。你恰好在上游很强：你会搭可验证环境、会分析和改进 agent 轨迹质量、懂安全任务的可打分性。你缺的是下游那段，但那段有概念框架就能上手（见 `08`）。

所以你的定位不是"一个不会训练的人",而是"一个懂可验证环境和轨迹质量、还亲手做过安全题的人，正好站在训练最缺原料的一侧，想把这套接到模型训练上"。

## 三、怎么讲"没训过模型"

诚实，但要讲出你理解到哪一层，并接到你会的东西。参考 `08` 第七节的三步模板。一句现成的话：

我没有独立训过大模型，我的经验在 agent、harness 和可验证环境这一侧。但我理解后训练的体系，RL 后训练的循环是采样、打分、算优势、更新，难点在异步的 off-policy 稳定性和稀疏长程的信用分配。这个循环的采样和环境两块我很熟，我做 agent 就是在生产这种轨迹、搭这种环境，我想补的正是把原料喂进训练循环、看指标调训练那一段。

不要做的事：假装训过、堆一堆术语但答不出细节、或者反过来过度贬低自己说什么都不会。承认边界加展示理解加接到强项，这个组合最稳。

## 四、把 ALE 安全实操接到这个项目（重要）

面试很可能顺着你的安全实操问，你要能把它从"我解了几道题"升华到"我理解怎么用安全任务训模型"。一段话：

我解那 4 道题的时候，其实一直在想它们作为训练任务好不好用。比如那道恶意样本配置提取是按 15 个字段打分的，天然是可验证的连续奖励，很适合做 RLVR；那道 keygen 是 flag 精确匹配，是最干净的 0/1 奖励；但 4 道题里有的绑死在 Windows 图形界面上，评测要读注册表、要在桌面上开 Ghidra，这类 GUI 交互很难无头自动化、也难批量重置，就不适合直接做 RL 训练环境，更适合做评测。所以我对"哪些安全任务能变成好的训练环境"有具体判断，这正是把安全推理内化进模型的第一步要解决的。

这段话把你从一个解题的人，变成一个懂"安全任务怎么变训练信号"的人，正中项目要害。

## 五、研究背景怎么点（点到为止，别喧宾夺主）

实习面试不用像答辩那样长篇讲你的论文，但可以用研究背景证明两件事：一是你有科研能力和好奇心（岗位明确要），二是你早就在想"内化进权重"这件事。一句话版本：

我硕士做复杂时间序列建模，有几篇一作和二作。博士转到自进化 agent，研究怎么在没有即时标签、反馈延迟的环境里让 agent 做信用分配和自我修正，核心就是 harness 引导轨迹再训练内化。所以"把能力内化进模型底层"这个思路，和我在做的方向是一致的，这也是我想加入这个项目的原因。

如果面试官对你的研究感兴趣深挖，再展开你那篇 pre-resolution temporal signals 的洞察（结果揭晓前用跨时间弱监督在线自我修正）。但主动权在你，别把实习面试开成答辩。

## 六、预判的背景问题

问：你没训过模型，为什么申这个岗位？答：因为我站在训练最缺原料的上游，会搭可验证环境、会分析改进轨迹、懂安全任务的可打分性，这些是把安全推理内化进模型的第一步就要用的。我想把这套接到训练上，补上后训练那段，这段我已经有概念框架，需要的是上手。

问：你安全基础不深，怎么补？答：我最近手工解过逆向、取证、已知明文攻击这些题，对安全任务有第一手体感，也系统过了 Web、二进制、密码、取证这些题型的知识体系。我不追求成为渗透专家，我要的是懂这些任务考什么、怎么变成可验证的训练环境，这个角度我已经能上手。

问：你 agent 做得多，会不会只懂 prompt 工程不懂底层？答：不会。我 debug 过模型和 harness 在工具协议层的不匹配、改过它的模型路由代码，也理解 RL 后训练循环、分布式并行、算子优化各在解什么问题。我对底层是有概念的，只是训练这一段还没亲手做，这正是我想补的。

问：你觉得这个项目最难的地方是什么？答：我的判断是不缺算法缺原料，难在怎么造出大量可验证、可复现、防作弊的安全训练环境，以及怎么解决安全任务奖励极稀疏、长程信用分配难的问题。这两个正好是我 agent 和环境经验能贡献的地方。
