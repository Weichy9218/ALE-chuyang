# 面试准备总导航（智谱实习面试）

明天下午是智谱 AI 和北京中关村学院联合实验室的实习面试。这套材料按这个目标重新组织。先读这篇理清定位和时间分配。

## 这个项目在做什么，要什么人

项目直接参与智谱新一代旗舰模型（GLM 系列）的训练，核心攻关方向是把网络安全推理和高阶代码能力内化进模型底层。它的立论是：前沿模型（Anthropic Mythos、GPT-5.6）在网络安全攻防和漏洞挖掘上的能力，和它们的深度代码理解一起带动了通用智能的跃升，所以安全场景下的深度代码推理，正在成为提升通用大模型智能的一条关键路径。

岗位优先要有这几类经验的人：大规模模型训练、RLHF/后训练、网络安全竞赛（CTF）、底层算子优化。核心素质是对前沿大模型训练有热情、能独立攻坚底层难题。

把这个和你的现状对一下，你的画像很清楚：

| 岗位维度 | 你的现状 | 今晚策略 |
|---|---|---|
| Agent / harness 开发 | 你的强项，有 pi、ale_claw、ALE 实操 | 讲透，作为你的立身之本，见 03 |
| 大规模模型训练 / RLHF / 后训练 | 你没训过模型，只开发过 agent | 最大落差，重点补，见 02 和 08 |
| 网络安全 / CTF | 基础薄，但刚手工解过 4 道逆向取证题 | 重点补知识体系，见 04、05 和可视化网页 |
| 底层算子优化 | 了解不深 | 知道大概在优化什么即可，见 08 |
| 前沿大模型 agent 研究 | 需要跟上智谱和唐杰系的最新工作 | 重 insight，见 07 |

你要面对的核心落差有两个：一是你做过 agent 但没训过模型，二是安全基础薄。这套材料就是围着这两个落差建的，同时把你 agent/harness 的强项讲成不可替代的价值。

## 你的一句话定位（背下来）

被问"介绍一下你自己、为什么适合这个项目"时用这句定调：

> 我的强项是 agent 和 harness 的工程，我把不同的大模型接进两套 harness 在一个可验证的 agentic 评测集上跑过、debug 过模型和 harness 的深层不匹配、也亲手解过几道逆向和取证的安全题。我没有独立训过大模型，但我恰好站在训练最需要的那一侧：可验证环境、工具交互轨迹、以及安全这类天然可打分的长程任务，这些正是把安全推理内化进模型要用的原料。我想补上后训练这一块，把我对 agent 环境的理解接到模型训练上。

这段话做三件事：亮出强项（agent/harness），诚实承认落差（没训过模型），并把落差转成互补（你懂的正是训练的上游）。诚实加互补，比假装什么都会强得多。

## 材料结构

- `00_导航与今晚计划`（本文）。
- `01_背景与定位`：怎么讲你的经历、怎么把"没训过模型"这件事讲得对你有利、怎么把 ALE 安全实操接到这个项目。
- `02_A_后训练_RL_verifier`：你最大的知识落差，后训练和 RL 的完整体系，配例题。
- `08_从做agent到训模型`：专门补你这个落差，一个只做过 agent 的人要理解训练时会碰到的东西，包括数据、loss、分布式、算子这些你没碰过的。
- `03_B_agent_harness`：你的强项，讲透 pi 和 ale_claw，接到"harness 引导轨迹再内化"。
- `04_C_web_appsec_ctf`、`05_D_代码安全_程序分析`：安全知识体系，配例题。不熟的部分配了可视化网页 `安全知识图谱.html`。
- `06_高频问答与话术`：模拟问答，含宏观问题和不会的题怎么答。
- `07_智谱GLM前沿与SAO论文`：智谱和唐杰系的最新研究（SAO、GLM-5 报告、slime、WebRL、协同进化这一波），重 insight。
- `09_安全与代码RL前沿`：这个岗位的正命题，用安全和 CTF 训练评估大模型的前沿（Cybench、CyberGym、CTF-Dojo、Big Sleep、XBOW、AIxCC、GPT-5 打 CTF），以及"安全推理为什么提升通用智能"的标准答案。

- `10_CTF实战_AI安全入门题`：一道真搭真解的 AI 安全题（pickle 反序列化 RCE），拆成 agent 想法-动作-观察轨迹，让你第一次看 CTF 也懂一个安全 agent 怎么解题。
- `11_可验证环境与稀疏奖励信用分配`：技术深度笔记，带公式。前沿怎么造大规模可验证环境、reward shaping 的理论（势塑形不改最优）、稀疏奖励和长程信用分配（GAE、hindsight、GiGPO、SAO 请回 value model）、防作弊。聊 RLVR 深水区用这篇。
- `12_安全reward设计与红蓝自博弈`：落到 ALE 4 道题的 result/process reward 与 verifier 具体设计（字段分解、可复算、状态势塑形、证据锚定），以及 AlphaZero 式红蓝自博弈怎么缓解策略飘移和分布收缩、以及它在哪会崩。

另有一个网页 `安全知识图谱.html`，把安全知识体系和几个你不熟的攻击原理画成图，适合今晚快速建立直觉。

## 今晚的时间分配

假设 4 到 6 小时。按落差和权重排：

1. 90 分钟：`02` 后训练体系 加 `08` 训练落差。这是你最缺、也是岗位最看重的。目标是能把 SFT、RLHF、DPO、GRPO、RLVR 讲清楚，能说清训练一个模型从数据到 loss 到分布式大概经过什么，能诚实地聊你没做过但理解到哪一层。

2. 75 分钟：`04`、`05` 安全知识 加 `安全知识图谱.html`。目标是建立每类漏洞和每类 CTF 题的直觉，能把它和"怎么做成可打分的训练任务"联系起来。先看网页建立图像，再看文档补细节和例题。

3. 45 分钟：`07` 智谱前沿。至少能聊 SAO、GLM 的方向、以及为什么安全推理能提升通用智能。

4. 30 分钟：`03` harness，把你的强项讲顺，接到训练。

5. 30 分钟：`01` 定位 加 `06` 问答，练开场和不会的题怎么答。

如果只剩 2 小时：`02` 加 `08` 加安全网页，把最大的两个落差补到能开口。

## 面试当天的三个动作

第一，用强项开路，用诚实补短。开场亮 agent/harness，被问到训练细节时不硬编，承认没做过但讲清你理解到哪、你会怎么上手。

第二，每个概念答完往你的实操引一句。问 reward hacking，落到你解安全题时见过的"直接 grep flag、钻打分脚本空子"。问可验证奖励，落到你手工对过参考答案的那 4 道题哪些能自动打分。

第三，把安全和代码往通用智能上引。这个项目的立论就是安全推理提升通用能力，你要能顺着这个立论说出自己的理解，而不是把安全当成孤立的技能。
