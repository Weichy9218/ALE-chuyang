# 高频问答与例题

按实习面试的场景组织。分五块：背景与动机、后训练与训练（你的落差）、安全（岗位核心）、宏观判断、以及不会的题怎么答加给面试官的反问。每块给若干例题，答案是要点不是逐字稿，用你自己的话说。

## 一、背景与动机

问：一分钟介绍你自己，为什么适合这个项目。答：强项是 agent 和 harness 工程，接过两套 harness 跑 ALE、debug 过模型和 harness 的深层不匹配、手工解过逆向取证安全题。没独立训过模型，但我站在训练最缺原料的上游，会搭可验证环境、会分析改进轨迹、懂安全任务的可打分性，这些是把安全推理内化进模型的第一步就要用的。想补上后训练那一段。

问：你没训过模型，为什么申这个岗？答：见 `01`。承认边界，讲清你在上游的价值，说你已有后训练的概念框架、要的是上手。

问：你觉得这个项目最难的地方？答：不缺算法缺原料。难在造出大量可验证、可复现、防作弊的安全训练环境，以及安全任务奖励极稀疏、长程信用分配难。这两个正是我 agent 和环境经验能贡献的。

## 二、后训练与训练（你的落差，重点练）

问：SFT、RLHF、DPO、GRPO、RLVR 什么时候用哪个？例题答：行为格式用 SFT 打底；主观偏好用 DPO 或 RLHF；答案可验证的能力（数学、代码、CTF）用 RLVR 配 GRPO 或 PPO，因为 verifier 比 RM 干净、on-policy 探索能学到示范外的解法。前沿是多阶段混合，SFT 冷启动、RLVR 提能力、拒绝采样回收再 SFT、通用对齐收尾。

问：PPO 的 clip 和 KL 是不是一回事？答：不是。clip 约束新策略离本轮采样策略多远，管优化稳定；KL 约束策略离初始参考模型多远，管不丢通用能力和抑制 reward hacking。参照物一个每轮变一个固定。

问：GRPO 为什么能不要 value model，SAO 为什么又请回来？答：GRPO 用组内平均当基线省掉 critic，适合同步、每题能廉价采一组。SAO 面对异步和在线单信号环境，组采样前提不成立，退回单轨迹后没组内基线，所以重训一个 value model 补上，再加双侧裁剪稳住。取舍随采样方式反转。

问：RLVR 是不是就没有 reward hacking？答：形态变了不是没有。verifier 不完备时模型钻它空子，比如写特判只过给定测试、读答案文件、利用评测环境漏洞直接拿 flag。要隔离评测环境、用隐藏充分测试集、收紧匹配、审计高分轨迹。

问：训练一个 750B 的模型大概要哪些并行？答：数据并行提吞吐、张量并行切单层大矩阵、流水线并行切层、ZeRO/FSDP 分片省显存，MoE 再加专家并行。我没亲手配过，但理解每种解决装不下还是跑得慢。

问：底层算子优化在优化什么？答：让矩阵乘、注意力这些算子在 GPU 上更快更省显存。核心矛盾常是内存带宽不是算力，FlashAttention 通过减少注意力的显存读写做快做省，算子融合减少反复读写显存，量化省带宽。我没写过 kernel，但理解目标是打掉内存搬运和冗余计算。

问：RL 后训练的循环讲一下。答：采样（模型生成轨迹）、打分（verifier 给 reward）、算优势（转成比平均好多少）、更新策略（提高高分 token 概率，配 clip 和 KL），再用新模型采样。系统难点是采样和训练要不要同步、actor 和 learner 分离、稀疏长程的信用分配。采样和环境这两块我很熟。

## 三、安全（岗位核心，重点练）

问：SQL 注入和 XSS 的根因是不是一回事？答：抽象层是同一类，数据越界进了某个解释器的语法层，SQLi 进 SQL 解析器、XSS 进浏览器 HTML/JS 解析器。解法同构，让数据待在数据位置：SQLi 参数化、XSS 上下文相关输出编码。区别在执行位置，XSS 危害绑定会话和用户身份。

问：现代 pwn 题为什么大多是两阶段？答：缓解叠加。NX 让你不能注入执行 shellcode，逼你用 ROP 复用已有代码；ASLR/PIE 又随机化地址。所以先泄露一个地址算出基址，再用溢出加 ROP 精确劫持控制流。这个结构要求维持长程状态，一步错全盘错，正是它作为 agentic 训练任务价值高的原因。

问：给你一道 Web CTF 题，怎么改成一个 RL 训练环境？答：容器化题目、锁依赖版本、网络隔离。flag 从硬编码改成实例化时随机生成、注入到只有解出题才能到达的位置，防 grep 和猜。verifier 做 flag 精确匹配或状态探针，和题目环境隔离、精确匹配不用子串。给模型能跑命令和 HTTP 的沙箱，记录轨迹，每 episode 干净重置。奖励先用 0/1，太稀疏再谨慎加中间里程碑，每个都要想清楚会不会被绕过刷分。

问：cyber 任务里最隐蔽的 reward hacking 是哪种？答：打 verifier 本身。不是解题而是攻击打分逻辑，比如子串匹配就把海量候选全打印命中、找到 verifier 读结果的可写文件直接改、状态检查只看端口有无响应就随便起服务占住。要让 verifier 和被测环境强隔离、判定当成会被攻击的对象加固。

问：为什么安全任务特别适合训练 agentic 能力？答：三个属性叠加。可验证（flag 或系统状态，奖励干净），强工具交互（必须真去执行命令读输出调整），长程推理（多阶段维持状态，一步错全盘错）。这个组合在别的任务域很难同时拿到。

问：为什么安全推理能提升通用智能？答：安全和漏洞挖掘本质是深度代码推理加长程、可验证、强工具交互的问题求解，训练模型在这种任务上做对，锻炼的是精确的多步推理、错误恢复、把工具反馈纳入决策的能力，这些是通用 agentic 智能的核心，所以在安全代码任务上变强会外溢到通用能力。这也是这个项目的立论。

## 四、宏观判断（考品味，用自己的话）

问：agent 能力该靠 harness 还是内化进模型？答：分工不对立。harness 是冷启动和探索的脚手架、管安全边界；内化换泛化和长程稳定。健康路线是协同进化，harness 引导可学习轨迹、训练内化、模型变强后 harness 退到更难处。终局 harness 尽量薄但不为零。

问：自进化或安全 agent 最大的瓶颈？答：不是模型不够聪明，是缺可靠可扩展的监督信号和环境。安全任务奖励稀疏、长程、还要隔离防逃逸，核心难题是造出可信可验证的训练环境和信号。

问：怎么看把攻击能力训进模型的风险？答：真实存在，要在隔离环境里训和评、控制模型和数据的释放、防环境逃逸，也要用去污染防止只是背了公开 writeup。能力越强治理越要跟上，这是这条路线绕不开的。

## 五、不会的题怎么答，和给面试官的反问

不会的题用三步，绝不硬编：一承认边界并给你知道的相关部分，二说你会怎么查证或想清楚（给具体路径不是空话），三接到你会的东西上。一句可用的话：这点我没把握，直觉是（给方向），但要验证，办法是（给路径）。诚实加推理路径远胜编一个错答案。

给面试官的反问，挑两三个：

- 这个项目现在把安全推理内化进模型，卡点更多在数据和环境的构造，还是训练算法和稳定性？
- 你们怎么界定"内化"成功，是看去掉工具脚手架后模型裸能力的提升，还是别的指标？
- 对一个 agent 和可验证环境很强、但没独立训过模型的人，你们期望他上手先补哪一块？
