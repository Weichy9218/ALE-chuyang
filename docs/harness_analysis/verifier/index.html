修复了 verifier 的「过度对冲」缺陷后，在先前的零分题和负向题上重跑，看倒扣有没有被消除。

修的是什么旧版把 unverifiable（公开材料无法测的检查）和真失败混在同一段呈现， writer 把「测不了」读成「有问题」，会把正确答案改成对冲答案。sse 就是这样丢分的：一道答对的题被改成 0.333。 修复：unverifiable 单列进中性的 NOT TESTABLE 段、删掉替 agent 论证的文字、并明写 「unverifiable 不是存疑信号」。详见 verifier/README.md。

结论修复后先前所有 verifier 负向题都回到 base 或以上：sse 0.333→0.667（q3 不再被翻）、 audience_seg 0.725→0.904。轨迹确认了机制（新 NOT TESTABLE 段出现、无 q3 改写命令）。

别过度解读n=1。修复后普遍走高里有一部分是这次抽样偏好（audience_seg、variant 两臂同分且顶到 base 上界）。 净效应约等于 base——修复消除的是倒扣，不是给 verifier 加了判分权。

怎么读

分数是台阶式的。sse 只有 0.3333/0.6667 两档，NSCLC 在 0.25/0.35 间跳。单题 delta 的正负往往是「落在哪一档」，不是「改进了多少」——这也是为什么单轮 n=1 不足以定论。

sse 的 prep 臂本轮掉到 0.333，与本修复无关：是证据摘录漏了一句 anchor 短语导致 q1 判 0（评分器逐字匹配的抽样方差）。见 总览 §3b。
