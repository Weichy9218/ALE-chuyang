题目本身

闭卷任务：依据 input/documents 下 7 份北京仲裁委员会（BAC）中文 PDF（《案件收费标准》及实施细则、退费标准、《调仲对接快速程序规则案件收费标准》、小时费率指引等），为 5 个案件各算三项金额——机构费用 institution_fee_rmb、仲裁员报酬 arbitrator_remuneration_rmb、总费用 total_fee_rmb，均两位小数。case_4 有特殊条件：当事人在申请仲裁前已就争议达成和解协议。仅可用 input/ 内材料，禁止外部检索。产出写入 output/arbitration_fee_results.json。

要求

必须且只写一个文件 output/arbitration_fee_results.json，顶层键 cases（数组），每 case 含 case_id 及三个被评分数值字段（amount_in_dispute_rmb、notes 选填），金额两位小数（output_contract.json 定义 schema）。可用 input/runtime_env 的 pyproject 装 PDF 解析包，但不得改动 input/。评测容差 ±0.01 元；单案权重 机构费7 + 仲裁员报酬7 + 总费用6 = 20 分，5 案共 100 分。

评测方法

main.py 先做存在性门槛：缺 output 文件、或缺 reference/answer_key.json、或 JSON 解析抛异常 → 直接返回 [0.0]。否则调用 scripts/score_outputs.py 的 score_submission。逐案逐字段二值判分：correct = 提交值非空 且 abs(提交−标准) ≤ TOLERANCE(Decimal('0.01'))，正确即得该字段权重（COMPONENT_WEIGHTS: institution_fee_rmb 7.0 / arbitrator_remuneration_rmb 7.0 / total_fee_rmb 6.0）。score = earned / (20×5=100)。字段名与 case_id 解析很宽容（别名 inst/arb/total，去逗号/RMB/元，case_id 归一化），但数值是硬判定；total_fee_rmb 独立对标准总额判分，不由另两项推导。故整体是 15 个分量的连续加权分，单分量为 ±0.01 的二值悬崖，没有全局 all-or-nothing（除文件/解析门槛）。

怎样才能做对

正解即模型所为，纯属「PDF 分档表解析 + 边际算术 + 特例识别」。(1) 从《案件收费标准》抽出两列边际公式（仲裁员报酬 / 机构费用），如「500万至1000万：报酬 55000+超500万部分×0.50%；机构费 23500+超500万部分×0.45%」。case_1(580万)→ arb=55000+800000×0.5%=59000、inst=23500+800000×0.45%=27100；case_2(6590万,4000万-1亿档)→ arb=190000+超4000万×0.31%=270297.86、inst=141000+…×0.25%=205756.34；case_3(8.82亿,5亿-10亿档)→ arb=1436000+超5亿×0.24%=2353953.52、inst=1061000+…×0.18%=1749465.14；case_5(≤25万保底)→ arb=12000、inst=5000。(2) case_4 特殊：「申请仲裁前已和解」触发《调仲对接快速程序规则案件收费标准》，其表为 C=(A+B)×收费比例，A/B 即普通表的仲裁员报酬/机构费用计算基数，「2亿(含)至5亿」档比例=25%；amount=2.516亿 → A=790212.36、B=589078.26，故 arb=A×25%=197553.09、inst=B×25%=147269.57、total=344822.66（按 (A+B)×25% 或两分量各自四舍后求和结果一致）。(3) 全程 Decimal + ROUND_HALF_UP 取两位。此题不需要模型不具备的能力。
