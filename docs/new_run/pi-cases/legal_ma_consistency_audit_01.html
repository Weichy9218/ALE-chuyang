题目本身

任务给出同一笔『新华百货 5% 股份协议转让』的四份中文监管披露文件（公告 + 受让方1/受让方2/转让方 三份简式权益变动报告书），已附逐页抽取的 UTF-8 文本（extracted_text/*.txt）和原始 PDF。要求交叉比对，找出所有可由文件支撑的事实性不一致，并写成一份英文审计报告，只保存一个文件 output/audit_report.md。每条发现需含英文标题、冲突说明、原始中文证据文字、以及『文档名+页码』定位标记，且不得编造无据的问题。

要求

唯一交付物 output/audit_report.md（英文、非空、<200KB）。评分参照 gold_findings.json 的 4 个 required_findings：target_a 公告第 1 页『重要提示』把『控股股东』误写成『空股股东』（Clerical）；target_b 公告第 2 页汇总表对受让方2 对价 146,660,323.00 比公告第 11 页与受让方2报告第 7 页的 146,660,332.00 少 9 元（Numerical）；target_c 聚源盛业在公告第 4 页记 45%、受让方1报告第 5 页记 40%（Structural）；target_d 公告第 2 页勾『√自有资金』但受让方1报告第 12 页称部分资金来自银行借款（Logical）。每个发现三档判定：命中(match)/证据文字(evidence)/页码定位(location)。

评测方法

main.py::evaluate 只读回 output/audit_report.md 与 gold_findings.json，交给 score_audit_report.py::score_report_text 用正则+关键词打分（不做语义/LLM 判定）。关键是硬门槛：`for finding: if matched: matched_target_ids.add(...)` 后 `missing_targets = [id for id in required if id not in matched]`，只要 `if missing_targets: return {"score":0.0, "reason":"missing_required_targets"}`——4 个必需发现缺任意一个即 0 分，且此时连假阳性都还没开始算就提前返回。全部命中后才进入扣分：`score=1.0; score-=0.2*false_positive_count; score-=0.2*len(evidence_penalty_targets); score-=0.1*len(location_penalty_targets)`。各 match 规则纯靠字面串：_match_target_a 必须 `'空股股东' in text`（外加 announcement 别名 + 控股股东/typo/clerical 等任一）；target_b 需同时出现 146,660,323 与 146,660,332 正则且提到 announcement+buyer2；target_c 需 45% 与 40% 且含『聚源盛业/合伙份额』；target_d 需『自有资金』+借款/银行。另有兜底：空输出返回 {"score":0.0,"reason":"empty_output"}，>200KB 返回 output_too_large——本例都不触发。

模型执行过程（逐帧）

两条轨迹几乎同构。OFF(24 步)：步3 读 task_brief.md + document_manifest.json，列出 extracted_text；步8 一次并行读入 announcement/buyer1/buyer2/seller 四份 txt（limit 2000，announcement.txt 仅 551 行，全文读到）；步13 用 pdftotext 复核受让方『法定代表人/执行事务合伙人』等页；步18 write 出 5 条发现；步20-23 自检（读回文件、find 输出目录、算 11281564*13=146660332 核对金额、rg 统计 Finding 与页码标记）。ON(23 步)基本相同，只是步16 先试 `apply_patch`（步17 报 command not found），步18 退回 write，同样步20-22 做了 `test -s ... 非空`、find、rg 自检。两份报告都写出：受让方2 差 9 元(target_b)、45%/40%(target_c)、自有资金 vs 银行借款(target_d) 三条且证据+页码全对；另各多写两条非金标发现——执行事务合伙人身份混淆、以及『公告称不涉及控股股东但转让方即控股股东』的逻辑质疑。两份都没有写出 target_a 的错别字『空股股东』。实跑评分器：两者 matched_targets=[target_b,target_c,target_d]、missing_targets=[target_a]、reason=missing_required_targets、score=0.0，且 b/c/d 三项 evidence_ok=location_ok=true。

哪里做错了

丢分的精确原因是唯一漏掉 target_a——公告第 1 页『重要提示』段把『控股股东』错写成『空股股东』的错别字。该错字就在已抽取文本 announcement.txt 第 15 行（Page 1）『空股股东物美科技集团有限公司…』，属两模型完整读入的区域；两模型甚至都围绕『控股股东』写了一整条 Finding 5（正确用了『控股股东』4 次），却把首次出现处被误写成『空股股东』这件事看漏了——本质是把单字错字(空↔控)自动脑补/略过的注意力/召回失误，而不是知识欠缺（它们明显认识『控股股东』一词）。评分器要求字面出现『空股股东』，grep 两份输出该串计数均为 0，故 target_a 判 match=false，触发『缺一即零』直接 0.0。雪上加霜：把 target_a 手工补入 OFF 报告后重跑，分数也只到 0.4（false_positive_count=3）——两条非金标发现（执行事务合伙人、控股股东逻辑质疑）按假阳性各扣 0.2，另有一条正确的金标发现因模型用 `**Why it is inconsistent:**` 加粗要点使评分器 _split_claim_units 解析碎片化而被误当假阳性。也就是说，即便补上错别字，这种报告风格的上限也就 0.4，过不了满分线。

怎样才能做对

1) 命中 target_a 是硬性前提：必须在报告里原样引用错别字串『空股股东』（如 `Announcement, Page 1: 空股股东物美科技集团有限公司`）并说明应为『控股股东』——不能只描述『控股股东』语义，必须保留错字字面。做对需要在逐字扫读中捕捉单字级别的中文错别字（空 vs 控），这对模型是可及的，但需要审计式逐字比对而非快速略读。2) 克制假阳性：任务明说『不得编造无据问题』，那两条非金标发现（执行事务合伙人身份、控股股东逻辑质疑，后者其实是误读——公告『不涉及控股股东变化』与转让方仍为控股股东本身并不矛盾）应删去；每多写一条按 0.2 扣。3) 迁就评分器解析：证据/说明要点尽量别用 `**加粗前缀:**`，否则 _split_claim_units 会把正确发现拆碎误判假阳性。理想满分=恰好 4 条金标发现、字面证据齐全、页码用『Document N, Page K』或『Announcement, Page K』且分号分隔，无多余发现。

harness（ON）的效应

无实质效果，ON 与 OFF 同分 0.0、同一漏项 target_a、同一组发现。ON 的镜像提示对本题全部冗余或不适用：M2『产物需存在且非空』——OFF 步20-23 已自查读回文件+非空+目录，ON 步20-22 同样 `test -s 非空`，本就做了；M1『预算紧张先写文件』——两次都在 23-24 步内从容完成，无预算压力；M4『别重复读未改文件/重跑失败命令』——无 thrash（ON 唯一重复是 apply_patch 失败后改用 write，属正常回退）；M3『按输入内暂存的参考自检直到达标』——根本不触发：本题既无数值达标阈值，输入树也不含任何参考/自检串（grep required_findings/target_a/『应为控股股东』等于 staged input 全部 NONE，document_manifest.json 只是文档元数据）。失败点是『没注意到一个中文单字错别字』+『多写了非金标发现』，这类内容级召回/取舍问题，纯状态镜像的提示无从修复，故 ON 未能改变结局。
