这是一个确定性的“复算 CDC FluSight 2021-22 评分卡”任务（输入已含全部预测与真值、算法在提示里被完整规定），模型按规范实现 WIS/rel_wis/MAE/coverage 管线，输出与答案键逐位吻合（误差约 1e-10），通过二值容差门，OFF/ON 均满分 1.0。

题目本身

在 Linux VM 上复现 2021-22 赛季 CDC FluSight 流感住院预测的“技能评分卡”。输入是 26 个真实参赛队已提交的分位数预测（forecasts_2021-22.parquet，2,101,010 行）和已观测真值（truth_2021-22.csv）。要产出两份 CSV：per_cell_scores.csv（每个 (model,location,target_end_date,target) 单元的 wis/ae_median/cov50_hit/cov95_hit）与 submission.csv（每个合格模型的 wis/rel_wis/mae/cov50/cov95）。本质是确定性的“打分/聚合”复算，而非真正的预测。

要求

提示把算法完整规定死：窗口 forecast_date∈[2022-02-21,2022-06-20]；target 取 1–4 wk ahead inc flu hosp；type=="quantile"；聚合前丢弃 location=="US"；23 个分位数（0.010…0.990）四舍五入到 3 位再匹配；round-outward（q<0.5 floor、q>0.5 ceil、q==0.5 银行家舍入）；WIS 归一化 1/(K+1/2)、K=11、11 个 alpha；缺分位的单元 wis/ae_median 记 NaN 再 fillna(0).mean()；合格性=非US分位行数≥Flusight-baseline的75%；rel_wis 用成对重叠单元 WIS 比值的几何均值（含自比1）再除以 Flusight-baseline 归一。输出列名/行粒度严格：submission 每个合格模型一行，per_cell 每个合格单元一行，另需 IEEE 754 双精度。

评测方法

评分完全二值——verify_output_bundle 只返回 score=1.0 或 0.0，无部分分。依次硬门：CSV 可解析→两表列齐全→submission 无重复模型→模型集合与 expected_table1 完全一致（extra/missing 皆空）→per_cell 行集合与 expected_per_cell 做 outer merge 后无 left_only/right_only（(model,location,target_end_date,target) 逐行精确对齐）→逐单元数值容差 CELL_TOL_WIS=0.001（wis 绝对）、CELL_TOL_AE=1e-6（ae_median 绝对）、cov50_hit/cov95_hit 整数精确相等→模型级容差 ABS_TOL_MODEL{rel_wis:0.005,cov50:0.005,cov95:0.005}（绝对）、REL_TOL_MODEL{wis:0.001,mae:0.001}（相对）。任何一处越界即整体返回 score=0.0。决定行：`return ScoreResult(score=1.0, passed=True, reason="ok")` 与全部失败分支 `_score_failure(...)`（score=0.0）。

哪里做错了

无失分——OFF/ON 都满分且稳健。模型输出与答案键逐位吻合：per_cell `CEID-Walk,01,2022-02-26,1 wk ahead inc flu hosp` 参考 5.7169565217 vs 模型 5.716956521739131（绝对误差约 4e-11，容差 0.001）；submission `CMU-TimeSeries` 参考 12.54/0.74/18.92/0.47/0.90 vs 模型 12.5394/0.7441/18.9175/0.4698/0.8969（rel_wis 差 0.0041<0.005、cov95 差 0.0031<0.005，wis/mae 相对误差约 5e-5<0.001，全部通过）。即使把容差再收紧一个量级也仍能过——满分极稳。

怎样才能做对

已做对。关键是解释“为什么可满分、而 flusight 不能”：(1) in-sample/确定性——预测与真值都在可见输入里，产物是对同一批输入的确定性重算，答案键 expected_* 正是同一算法的输出，没有留出任何待预测目标；(2) 算法被提示完整规定（分位集、round-outward、1/(K+1/2)、K=11、alpha、75% 合格、几何均值 rel_wis），无建模判断余地；(3) 评分是“精确复现”的二值容差门，正确实现 pandas 管线即过。对照姊妹任务 flusight_offline_hosp_forecast_2024_12_14：那是真·预测（用 2024-12-14 历史快照预测未来周住院数，真值留出），评分是连续技能分 `score = 1.0 - (candidate_wis / baseline_wis)` 并 clamp 到 [0,1]，要拿 1.0 需 candidate_wis=0 即完美预测——不可达；~0.74 表示已把 WIS 相对朴素基线降约 74%，残差是不可约的预测不确定性。故满分与封顶之别，是“复算 vs 预测 + 二值门 vs 连续精度分”的结构性差异，而非容差更松（本题容差 rel 0.001 反而不松）。

harness（ON）的效应

ON 对结果无实质影响，两侧同为 1.0；ON 略快（24 vs 31 步）属正常波动而非镜像提示所致。OFF 在无提示下已自发完成全部被镜像的行为：M2（产物存在且非空）OFF 用 `find -type f`/`wc -l`/读文件头显式核验；M4（防抖）OFF 的两处报错（uv 缓存、`.quantile`）是正常迭代修复，无重复空跑或重读未改文件；M1（预算）31 步远在预算内、且已先写文件。M3（对照参考自检直到达标）在本题根本无处落地：答案键 expected_table1/expected_per_cell 位于 reference_dir、不在 agent 可见输入（manifest visible_inputs 仅 forecasts_2021-22.parquet 与 truth_2021-22.csv），M3 仅当“数值目标+输入可见参考”同时存在时触发，此处无可见参考，镜像至多重述“确认输出存在/内部一致”——恰是 OFF 已做的。结论：镜像提示在此任务冗余。
