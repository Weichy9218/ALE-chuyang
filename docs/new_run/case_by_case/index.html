评测方式三类：程序化打分 确定性 Python 脚本，多数对照隐藏参考答案做数值容差或字段比对，结果可复现；隐藏测试套件 用 shell 断言批量跑通过率；LLM 裁判 用模型逐问打软分，含随机性。本域只有 pe_screening 一题用 LLM 裁判，其余 11 题全是确定性自动评测。
