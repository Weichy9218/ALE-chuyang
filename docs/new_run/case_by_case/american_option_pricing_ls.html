题目做什么

三个 Tier 难度递增，共用同一套 GBM 模拟约定：风险中性测度下用精确对数正态公式推进价格 S(t+dt)=S(t)·exp((r−0.5σ²)dt+σ√dt·Z)，禁止用 SDE 的 Euler 离散，随机数种子统一 numpy.random.default_rng(77777)。

Tier 1：欧式看跌，Black-Scholes 校准

参数：S0=100，K=100，r=0.05，sigma=0.2，T=1.0。要做四件事：

  • 算 Black-Scholes 闭式看跌价 P = K·e^(−rT)·N(−d2) − S0·N(−d1)。
  • 算 Greeks：Delta = N(d1)−1，Gamma = N'(d1)/(S0·σ·√T)，Vega = S0·N'(d1)·√T，Theta。
  • 跑 10 万条路径的蒙特卡洛，作为验证。
  • 验证 MC 价落在 BS 价的 2 倍标准误之内。

这一层是校准，确认模拟框架本身没写错，为后两层的美式定价托底。

Tier 2：单资产美式看跌，Longstaff-Schwartz

参数：S0=100，K=110（实值），r=0.05，sigma=0.2，T=1.0，10 万条路径，100 个时间步（即 100 个可行权时点），回归多项式次数 3。

这一层是题目主体，要点在于 Black-Scholes 在这里会算错。BS 给的是欧式价约 10.68，而实值美式看跌可以提前行权，真实价约 12.00，提前行权溢价约 1.25，占欧式价约 12%。用 BS 给美式看跌定价，绝对误差会超过 1.0。

Longstaff-Schwartz 的做法是在模拟路径上做反向归纳：在每个行权时点，把继续持有的未来贴现现金流对当前状态变量的多项式基做横截面回归（用 numpy.linalg.lstsq），估出继续持有价值，当即时行权收益超过它就行权。题面点名了几个实现细节：

  • 只用实值路径进回归（即时收益 max(K−S,0) 为正的路径）。
  • 回归前把 S 标准化 x=(S−mean)/std 再造基 [1, x, x², x³]，否则 S 在 100 附近时 degree-3 的 Vandermonde 矩阵病态。
  • 实值路径数少于 poly_degree+1 就跳过这一步，该步无人行权。
  • 时间 0 不作为行权时点，反向归纳从第 N_steps−1 步做到第 1 步。

还要输出行权边界：每个时间步记录当步行权路径里的最高资产价，连起来就是估计出的提前行权边界。

Tier 3：5 资产相关篮子美式看跌加 Greeks

参数：5 个资产，S0 全 100，sigma=[0.18, 0.22, 0.25, 0.20, 0.28]，篮子权重=[0.25, 0.20, 0.20, 0.15, 0.20]，篮子行权价 K=95，r=0.05，T=1.0，两两等相关 rho=0.3，20 万条路径，100 步，回归次数 3。

篮子价是 5 个资产的加权和 B(t)=Σ w_i·S_i(t)，看跌收益是 max(K−B(t), 0)。相关路径靠对相关矩阵做 Cholesky 分解，每步先取 5 个独立标准正态 epsilon，再 Z = L @ epsilon 得到相关增量。回归基比单资产丰富：篮子价及其各次幂，加每个资产价的一次和二次项（标准化），共 1 + poly_degree + 2·N_assets = 1 + 3 + 10 = 14 个特征；要求实值路径数至少 2·poly_degree·N_assets + 1 才做回归。

Greeks 用 pathwise 法在冻结行权边界的前提下算：先用 LS 定出每条路径的停时 tau，再对贴现收益就参数求导，行权决策保持不变。Delta_j 对初值 S0_j 求导，逐路径导数 −w_j·S_j(tau)/S0_j；Vega_j 对波动率 sigma_j 求导，逐路径导数 −w_j·S_j(tau)·(−σ_j·t + BM_j(t))，其中 BM_j(t) 是资产 j 到时间 t 的累计相关布朗增量。每个 Greek 是对应贴现导数在所有路径上的均值。

失分的典型形态

按 task_card.json 的 evaluation 说明和打分逻辑，拿不到 1.0 通常是这几种：

  • 缺输出文件，或 results.json 不是合法 JSON，直接 0.0。
  • 只在 JSON 里编指标，而 exercise_boundary_tier2.npy 对不上 exercise_boundary_sample，Tier 2 判负。
  • 行权边界不合理：形状不对、有限项不够、超出 [70, 115]、尾部中位数不到 95、或单调违背超过 2 次。
  • Tier 2 的美式价塌回欧式价，说明提前行权逻辑没生效，溢价过不了 > 0.5 或 bs_underestimates 不为 true。
  • Tier 3 的 Greeks 符号错（有 delta 非负或 vega 非正），或某个 Greek 量级偏离参考 3 倍以上。
  • Tier 1/Tier 2 如实做出、Tier 3 缺失或没过，拿 0.5。
