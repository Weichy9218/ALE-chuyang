数值计算与复现

ALE 逐题轨迹分析。pi 与 gpt_claw 同模型 gpt-5.6-sol、同环境跑同一批题，看两套 harness 各做了什么、为什么是这个分。红色步是报错的工具调用。
总览文档审计与分类结构化财务抽取临床数据与生物统计数值计算与复现
这批运行时 gpt_claw 的交互轮数被限制在 30 轮，事后看太低也不公平：它的多数空输出失分直接来自这个上限，何况它还要花轮次在委派子 agent 和脚本拼装上。已把上限改到 100。之后的 ALE 任务模型走 boyue 网关（apirx.boyuerichdata.com）。本页分析基于 30 轮上限的运行结果。

两题都是数值计算，但性质相反。一题是复现一个定义明确的评分卡，有唯一正确输出、按容差评；一题是开放式优化，要把重建图像的 SSIM 迭代到硬阈值。前者两套都满分，后者两套都 0。

这一组题的 harness 优化方向

  • 流程明确、有唯一正确输出的复现题（epidemiology），两套都满分，不需要干预。
  • 开放式优化到硬阈值的题（ct_geometry），harness 能做事实反射：每轮迭代后把当前 SSIM 和 MSE 与目标阈值的差距回注到观察里，让 agent 稳定地面对差距。pi 已经在自己算 SSIM，但由 harness 稳定反射能避免 agent 忘记跟踪。
  • 止损也有用：ct_geometry 上 pi 跑到超时仍是 0，一个'连续若干轮无改进就停'的护栏能省算力，把预算留给别的题。
