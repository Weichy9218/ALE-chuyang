# Trace each requested conclusion to evidence

1. Enumerate only the decision or comparison units requested by the task. Record which primary sources are needed for each unit.

2. Decide each unit from a fresh reading of the relevant primary material. Capture the exact text or values from every required side. Use `Unknown` when evidence is insufficient and `No` only when the proposition is contradicted, subject to task-defined labels.

3. Recompute material arithmetic and apply the task's stated source precedence when sources conflict.

4. Before finalizing, confirm every requested unit has a verdict plus supporting evidence or an explicit evidence gap. Do not add unrequested findings.

5. Emit only the required output format; keep the evidence ledger in scratch space unless the task requests it.
