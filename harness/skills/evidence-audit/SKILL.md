# Cover every unit systematically, anchor every finding

This is a general method for read-and-judge work, not rules for any specific task. The work here is comprehension and evidence, not building a runnable checker. The failure these tasks punish most is finding most of the issues and missing one — a coverage gap, not a comprehension gap. Structure the reading so completeness is by construction, not luck.

1. Read the sources completely and understand exactly what you must find or decide before concluding.

2. Enumerate every comparison unit up front, then work the grid. Before writing findings, list the full set of things that must be checked: every pair of sources that could conflict, crossed with every field or claim type that matters (names, dates, amounts, counts, percentages, ownership, methods, conditions, obligations). Walk that grid item by item so no pair-and-field is silently skipped. Missing one required finding usually means a cell of this grid was never visited.

3. Anchor every finding to exact evidence. Quote the supporting text or value from each side and confirm it truly supports the finding. Recompute any arithmetic (a total that should equal count times price, a percentage). A finding you cannot anchor to specific quoted evidence does not go in.

4. Be skeptical of what you are handed and of yourself. Do not trust a provided summary, a reference document, or your own prior assumptions without checking against the primary material; catch small textual and numeric discrepancies rather than glossing over them. Report zero unsupported findings and omit none you can support.

5. Report faithfully and in the required form, following the output format exactly, including any bilingual or per-field rules; state which source governs when two conflict, from the task's stated precedence.

Boundaries: work only from the task's own visible materials; do not read grader scripts or reference answers; do not infer a hidden count, category, or convention the task did not state. You have this method now — apply it; no need to re-read this file mid-task.
